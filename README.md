# ToonShelf 3.1.2

[Windows 최신 버전 다운로드](https://github.com/redmonBI/ToonShelf/releases/latest)

ZIP을 새 폴더에 풀고 `ToonShelf.exe`를 실행합니다. `_internal` 폴더를 함께 유지하세요. 웹 조회에는 Chrome 또는 Edge가 필요합니다. 다운로드한 작품·이미지는 공유 저장소에 올리지 않습니다.

## 3.1.2 업데이트

사이트 주소에는 일반 URL, 도메인, 붙여넣은 `[주소](https://...)` 링크를 사용할 수 있습니다. 링크 표기를 실제 주소로 정리하고 http/https 여부를 검사합니다. 메인 주소는 설정 저장 또는 목록 불러오기 시 정리됩니다.

상단 **메뉴 접기**를 누르면 왼쪽 메뉴를 아이콘으로 줄입니다. 아이콘에 마우스를 올리면 메뉴 이름을 확인합니다. **저장 규칙 숨기기**는 오른쪽 저장·진행 패널을 숨겨 작품 영역을 넓힙니다. 다운로드 시작은 상단 버튼을 사용하고, 진행·중단은 대기열 메뉴 또는 패널을 다시 표시해 확인합니다. 두 화면 설정은 다음 실행에도 유지됩니다.

작품 목록과 다운로드 라이브러리 하단의 숫자 버튼으로 페이지를 바로 이동합니다. 페이지가 많으면 첫·마지막 페이지와 주변 번호를 표시합니다. 오른쪽 **이동** 칸에 원하는 번호를 입력하고 Enter를 눌러도 됩니다. 검색이나 필터를 바꾸면 첫 페이지로 돌아갑니다.

왼쪽 **세부 설정 → 테마**에서 화이트·다크·레인보우·회색·강조형을 선택합니다. 선택 즉시 목록, 라이브러리, 내장 뷰어 주변과 프로그램의 설정 창에 적용하고 자동 저장합니다. 작품 이미지 원본과 OpenComic 별도 창의 테마는 바꾸지 않습니다.

3.1.2부터 상단 **업데이트 확인 → 선택 버전 패치 · 프로그램 재시작**으로 기존 폴더에 업데이트합니다. 3.1.1 이하의 업데이트 화면은 예전 방식이므로 이번 한 번은 내려받은 3.1.2 실행 파일과 구성 파일을 기존 폴더에 적용해야 합니다. 개인 state 폴더와 작품 파일은 유지하세요.

## 새 라이브러리와 읽기

왼쪽 **다운로드 작품**에서 현재 저장 폴더에 등록된 작품을 표지 카드로 봅니다. 검색·장르·최근 다운로드·이름·용량 정렬과 페이지 이동을 제공합니다. 목록 용량은 보관함 기록 기준이며 실제 누락·손상 검사는 읽기와 내보내기 작업에서 진행합니다. 보관함에 기록이 없는 파일은 **보관함·내보내기**에서 먼저 등록하세요.

**뷰어 설정**에서 내장 뷰어와 OpenComic 별도 창을 선택합니다. 내장 뷰어는 인터넷 없이 세로 스크롤로 읽고, 회차 선택·이전/다음 화·읽기 폭·회차별 읽던 위치를 보존합니다. Alt+← / Alt+→로 회차를 이동합니다. 기록된 이미지 순서를 우선하며, 순서 기록이 없는 이전 자료는 숫자 파일명 순서로 표시합니다. 누락·손상 이미지는 해당 위치에서 안내합니다. 보이는 부분만 배경 작업으로 읽고 표시용 이미지 메모리를 제한합니다. 원본 픽셀 수가 1억 2천만을 초과하는 이미지는 안내로 대체합니다.

OpenComic **1.6.5 공식 폴더형 포터블**을 포함합니다. 선택한 회차를 직접 열고, 프로그램의 작은 회차 이동 창으로 앞뒤 회차를 엽니다. OpenComic 자체의 웹툰 모드를 선택하면 세로로 읽을 수 있습니다. OpenComic의 자체 읽기 설정은 독립적으로 보존됩니다. 내장 뷰어는 별도로 구현한 뷰어이며 OpenComic을 창 안에 억지로 삽입하지 않습니다.

읽는 순서를 맞춘 `.toonshelf-reader` 폴더를 저장 폴더 안에 만듭니다. 원본 파일 이름과 내용은 변경하지 않습니다. NTFS 등 지원 저장소에서는 하드 링크를 사용하여 이미지 용량을 추가하지 않습니다. 하드 링크를 지원하지 않는 저장소는 사본 공간이 필요하며 여유 공간을 검사합니다. 스마트폰으로 옮길 자료는 **보관함·내보내기**의 숫자 순서/CBZ 기능을 이용하세요.

OpenComic 저작권·라이선스는 `Vendor/OpenComic/LICENSE_OpenComic.txt`, 대응 소스·빌드 안내는 `SOURCE_AND_NOTICE.txt`에 있습니다. [공식 소스 v1.6.5](https://github.com/ollm/OpenComic/tree/v1.6.5) 및 [동일 버전 소스 ZIP](https://github.com/ollm/OpenComic/archive/refs/tags/v1.6.5.zip)을 원본 배포처에서 제공합니다. 공식 실행 파일은 수정하지 않았습니다.

## 화면 반응과 다운로드 시간

보관함 검사와 내보내기 준비·변환을 배경 작업으로 처리하고 **불러오는 중 / 내보내는 중** 표시를 제공합니다. 폴더 선택 창은 Windows의 저장 장치·네트워크 응답에 따라 시간이 걸릴 수 있습니다.

다운로드 화면에 **실효 속도**와 **현재 작품 예상 남은 시간**을 표시합니다. 실효 속도는 최근 이미지 처리 바이트를 기준으로 하며 브라우저 대기·캐시 사용을 포함하므로 네트워크 회선 속도와 다릅니다. 회차별 이미지 수를 추정하므로 초기에는 계산 중이고, 이미지 크기나 연결 상태가 바뀌면 예상 시간이 달라집니다. 일시정지 시간은 계산에서 제외합니다.

## 작품 대기열

체크한 작품의 다운로드 버튼을 누르면 대기열에 들어갑니다. 이미 대기 중인 같은 작품·저장 위치·회차 범위는 중복 등록하지 않습니다. 작품별 상태, 현재 회차·이미지 위치, 시도 횟수와 오류를 표시합니다. 상태는 매 이미지 진행에 기록합니다. 비정상 종료 후 진행·일시정지 작품은 **중단**으로 복구하고 자동으로 다운로드하지 않습니다.

- **전체 대기열 실행**: 대기·중단 작품을 진행합니다. 보류·취소 작품은 자동 재개하지 않습니다.
- **재개**: 선택 작품을 대기로 바꿉니다. 이미 저장한 파일은 해시 검사 후 건너뜁니다.
- **중단**: 현재 요청을 마친 뒤 멈춥니다. 전역 중단은 다음 작품의 자동 시작도 멈춥니다.
- **보류 / 취소**: 해당 작품을 진행 대상에서 뺍니다. 저장한 파일은 삭제하지 않습니다.
- **우선**: 현재 작품을 강제로 끊지 않고 다음 작품 선택에서 우선 처리합니다.
- **일시정지**: 현재 작품의 다음 요청을 기다립니다. 재실행해도 회차·이미지 위치 기록을 보존합니다.

다운로드 중에도 별도 브라우저 작업으로 **목록 불러오기 / 전체 갱신**이 가능합니다. 조회 시점의 목록을 새로 읽고 진행 중 작품의 저장 위치·회차 설정은 바꾸지 않습니다. 실제 파일을 이어받는 방식이므로 페이지 자체는 다시 조회할 수 있습니다.

## 종료 예약

사이드바의 **종료 예약**에서 프로그램 종료, PC 종료, PC 강제 종료를 선택합니다. 조건은 대기열 완료 후, 지정 시각, 분 단위 타이머입니다. 시각 입력은 한국 시간입니다. 완료 후 종료는 실패 여부에 관계없이 대기열의 진행 대상이 끝나면 작동합니다. 보류·중단·일시정지 작품이 있거나 모두 취소하면 완료 후 종료하지 않습니다.

**실패 작품은 한 번 더 시도**를 켜면 실패·부분 완료 작품을 한 번 더 받습니다. 연속 접근 거절로 서버 제한을 감지한 작업은 자동 반복하지 않습니다. 설정은 향후 시도에 적용되며 이전 파일은 유지합니다.

PC 종료에는 프로그램 안에서 60초 예고를 표시하고 취소할 수 있습니다. 예고 후 일반 종료는 Windows의 일반 종료 명령을 사용하고, 강제 종료만 `/f`를 사용합니다. 다른 앱의 미저장 작업을 강제로 끝내는 기능은 강제 종료에만 적용합니다. 프로그램을 닫거나 재실행하면 종료 예약은 꺼집니다. 실제 PC 종료를 실행한 테스트는 하지 않으며 명령과 시각은 모의 실행으로 검사합니다.

## 목록·장르·저장 공간

장르·제공처 검색과 장르 제외·숨김을 제공합니다. 숨김은 체크한 장르 중 하나라도 포함하는 작품에 적용하며, **숨긴 장르 보기**로 다시 볼 수 있습니다. 저장 장치 여유 공간을 10초마다 갱신합니다.

인기순은 **커뮤니티 추천 동감 수**, 신작순은 **갱신 때 처음 발견한 작품의 시각**을 기준으로 합니다. 사이트 전체 인기나 실제 연재 시작일을 제공한다고 표시하지 않습니다. 기존 목록의 최초 발견일은 미확인으로 취급합니다. 최신 회차순은 목록의 회차 숫자를 기준으로 하며 업로드 날짜순과는 다릅니다.

## 친구 추천과 사이트 공유

공유 저장소: [redmonBI/ToonShelf](https://github.com/redmonBI/ToonShelf)

프로그램의 **친구 추천**에서 추천인 이름, 작품명, 장르, 추천 내용, 선택 작품 링크를 작성합니다. GitHub 요청 작성 화면이 열리면 본인 GitHub 계정으로 로그인하고 **Submit new issue**를 누릅니다. 서버 역할의 GitHub Actions가 요청을 읽고 공유 JSON 목록을 갱신합니다. 자동 처리 후 프로그램에서 새로고침하면 표시됩니다. 평소에는 수십 초~몇 분이 걸릴 수 있고, 정기 처리는 15분 간격입니다.

모든 GitHub 이용자가 추천 작성·수정·삭제와 공유 사이트·최신 링크 등록·삭제를 할 수 있습니다. 관리자 승인이나 저장소 쓰기 권한은 필요하지 않습니다. 동감은 추천마다 GitHub 계정당 하나이며 다른 표시 이름을 입력해도 중복 투표할 수 없습니다. GitHub 요청 원문을 수정해도 이미 등록된 추천은 수정되지 않습니다. 등록일과 수정일은 공유 데이터에 UTC로 보존됩니다.

공유 저장소는 공개이며 추천·추천 내용·표시 이름·사이트 링크·동감 계정도 공개됩니다. 친구에게 저장소 쓰기 권한이나 관리자 토큰을 줄 필요가 없습니다. 공개 저장소이므로 지인 외 다른 GitHub 이용자도 새 추천 작성은 가능합니다. 지인 전용 비공개 운영이 필요하면 별도 저장소 접근 정책이 필요합니다.

**사이트·최신 링크**에는 개인 링크와 공유 사이트, 최신 소식 페이지 주소를 등록합니다. 개인 링크는 이 PC에만 저장합니다. 웹 최신 조회는 페이지에 공개된 회차·업데이트·신작 등의 링크를 읽으며 사이트별 구조에 따라 결과가 없을 수 있습니다. 원문은 더블클릭해서 확인합니다. 이 기능은 모든 다른 사이트의 다운로드 어댑터를 자동 제공하지 않습니다. 기본 다운로더는 기존 지원 사이트 구조를 사용합니다.

## 친구들의 업데이트

버튼에 설치 버전을 표시하고 시작 후·6시간마다 GitHub Releases를 확인합니다. 새 정식 버전이 있으면 버전과 게시 날짜를 표시하며, 버튼을 누르면 업데이트 내역과 과거 버전 기록을 볼 수 있습니다. 네트워크 실패는 최신 버전이라고 표시하지 않습니다.

업데이트는 ZIP과 SHA256SUMS를 내려받아 검증한 다음 패치 파일을 준비합니다. 준비 중에는 로딩 표시를 제공합니다. 프로그램이 종료되면 별도 도우미가 같은 설치 폴더의 실행 파일·구성 파일·포함 뷰어를 교체하고 프로그램만 다시 시작합니다. 개인 state·작품·추가 파일은 교체하지 않습니다. 변경 파일의 복구본과 적용 결과는 설치 폴더의 Updates에 보존하며, 교체 실패 시 기존 파일로 복구 후 실행합니다. 다른 앱이 파일을 잠그거나 저장 장치 오류로 복구가 불가능하면 결과 기록과 복구본을 안내합니다. 기록은 state/update_history.jsonl에도 남습니다. 다운로드·조회 중에는 적용할 수 없으며 종료 예약은 취소됩니다.

개발자는 소스를 수정하고 `sharing.py`의 VERSION을 올린 뒤 RELEASE_NOTES를 작성하고 GitHub의 **Actions → Build and publish Windows release → Run workflow**를 실행합니다. 검사와 Windows 빌드가 성공하면 새 릴리스와 검증 파일이 게시됩니다. 같은 버전을 의도적으로 재배포하면 해당 버전의 파일과 검증값을 갱신합니다.

## 기존 보관함

2.x의 이미지와 `.toonshelf.sqlite3`는 그대로 사용할 수 있습니다. 저장 폴더를 지정하고 보관함을 등록하세요. 업로드일·첫/최근 다운로드일·용량·장르·제공처 수정과 회차별 CBZ/숫자 순서 이미지 내보내기를 유지합니다. 원본을 보존하면서 JPEG 품질·가로 크기를 조절할 수 있습니다. 불완전·손상·읽는 순서 미확인 회차는 내보내기 전에 확인합니다.

## 검사와 소스 실행

`install.bat` → `run.bat`. 개발 검사: `python -m unittest test_core test_library test_v3 test_reading test_appearance -v`. PC 종료 검사는 가짜 실행기로 검사하며 사용자의 PC를 종료하지 않습니다. 실행 파일 제작은 항상 새 빌드 경로와 `--clean` 옵션을 사용하세요.

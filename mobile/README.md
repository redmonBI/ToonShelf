# ToonShelf Mobile 3.6.0

Android 스마트폰·태블릿의 Chrome에서 https://redmonbi.github.io/ToonShelf/mobile/ 을 열고
메뉴 → 앱 설치 / 홈 화면에 추가를 선택합니다. 스토어 APK가 아닌 설치형 웹앱(PWA)입니다.

PC 계정으로 로그인 → 서버 목록 불러오기 또는 PC의 모바일 메뉴에서 내보낸 목록 JSON을 가져옵니다.
PC의 기기용 내보내기에서 회차별 CBZ를 내보내 기기로 옮기고 파일 가져오기를 선택합니다.
원본 이미지 여러 개를 선택해 작품명·회차를 직접 지정하는 방법도 지원합니다.
ToonShelf CBZ는 기록된 순서·회차·작품 정보로 연결되고, 일반 CBZ는 파일명 숫자순으로 읽습니다.

가져온 이미지는 IndexedDB에 저장하고 업로드하지 않습니다. 목록·읽기 기록은 기존 HTTPS 계정 API를
사용하며 충돌(409) 시 덮어쓰지 않고 서버 목록을 다시 불러옵니다. 자동 로그인은 비밀번호가 아닌
세션 토큰만 저장합니다. 기기 파일은 계정 변경 후에도 기기에 남으며 독서 기록은 계정 전환 시 초기화합니다.

첫 실행은 인터넷 연결이 필요합니다. 이후 앱 화면·가져온 이미지 읽기는 오프라인으로 가능합니다.
기기/브라우저가 저장 공간을 정리할 수 있으므로 PC 원본을 보관하세요. CBZ는 회차별 128MB,
압축 해제 후 200MB, 이미지별 32MB·5000개 이하입니다. 해제는 별도 작업자에서 수행하고
회차 저장은 원자적으로 처리합니다. 한 회차 저장 실패는 기존 보관 회차를 훼손하지 않습니다.

모바일 앱은 PC 자동 다운로드를 원격으로 실행하거나 백그라운드 다운로드하지 않습니다.
PC 예약은 PC 프로그램이 실행 중일 때 처리됩니다. 신규 버전은 다시 실행할 때 캐시를 갱신하며
가져온 기기 데이터는 별도 저장소에 유지합니다.

개발: npm test (순수 모델 검사), localhost 정적 서버에서 실기능 검사.
외부 실행 코드/CDN 없이 vendored fflate 0.8.2 (MIT)를 사용합니다.

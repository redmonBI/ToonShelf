# ToonShelf Android 3.7.2

Android 스마트폰·태블릿에 Android APK를 설치합니다. Chrome 설치나 웹 페이지를 항상 열어둘 필요가 없습니다. 화면·뷰어 파일은 APK에 포함되며 화면 크기에 따라 자동 배치합니다. Android 8 이상이 대상입니다.

## 대표 다운로드 폴더

1. PC 다운로드 대표 폴더를 스마트폰·태블릿·SD카드로 옮깁니다. 작품/회차/이미지 구조를 유지하세요.
2. `.toonshelf.sqlite3` 또는 회차별 `_reading_order.json`을 함께 옮기면 PC의 순서·작품 링크·제공처·요일·날짜를 읽습니다. 기록이 없으면 이미지와 회차 이름의 숫자를 기준으로 정렬합니다.
3. 앱에서 **대표 폴더 불러오기** → 폴더 선택 → 사용 허용. 하위 폴더를 찾으며 진행과 취소를 표시합니다. 폴더 선택과 최근 검색 목록을 기억합니다. **폴더 새로고침**으로 변경 파일을 반영합니다.
4. Android 11 이상은 저장소 전체, Download 최상단, Android/data 같은 보호 경로를 선택할 수 없습니다. `Download/ToonShelf`처럼 작품 전용 하위 폴더를 선택하세요.

APK는 선택한 이미지 원본을 앱 저장소에 다시 복사하지 않습니다. 원본을 이동·삭제하거나 SD카드를 분리하면 읽을 수 없습니다. 폴더에 접근할 수 있으면 비행기 모드에서도 회차 이동·세로 읽기·위치 저장을 사용할 수 있습니다. 기기 목록·계정 캐시와 이미지 파일은 별개입니다. 계정 서버에 이미지는 올리지 않습니다.

## 모바일 기능

- 기존 계정 로그인·가입·로그아웃, Android Keystore로 암호화한 자동 로그인 세션. 비밀번호를 저장하지 않습니다. 목록·즐겨찾기·설정·읽기 위치·다운로드 이력을 서버와 수동 동기화합니다. 충돌 시 서버의 변경을 덮어쓰지 않습니다.
- 사이트 전체 목록을 별도 조회 화면에서 읽으며 다운로드와 독립적으로 갱신합니다. 직접 사이트 주소와 등록 사이트 선택·주소 이력·예정 주소를 지원합니다. 링크는 일반 URL·도메인·Markdown 붙여넣기를 정리합니다.
- 보고 있음·보류 중·볼 예정 목록, 요일 복수 체크·장르·제공처·즐겨찾기, 최근/전회차/다운로드 전 탭, 숫자 페이지 이동. 기록이 없는 전회차 여부는 최근/일부 회차로 표시합니다.
- 작품별 동시 다운로드 1~4, 전체/최신 1·5·10·20·30화, 진행 그래프·속도·남은 예상 시간, 중단·일시정지·보류·취소·우선·재개. 이미지 이름을 유지하고 중복 이름은 접미사로 구분합니다. 100×100 이상의 본문 이미지만 받습니다. 접근 거절은 실패로 표시합니다.
- 전체 이미지 전송 속도와 시간대 제한. 다운로드 허용 시간을 벗어나면 Android 작업 관리에 대기합니다. 매주 요일·한국 시간 예약, 목록 전체 또는 체크한 작품 업데이트. Android 절전·배터리·백그라운드 정책에 따라 예약 실행은 지연되며 정확한 분 단위 실행을 보장하지 않습니다. 강제 중지 후에는 앱을 다시 실행하세요.
- 자동 정리는 기본 꺼짐. APK가 직접 저장·검증한 이전 회차만 대상으로 최신 N화와 기간을 설정합니다. 읽는 동안 보류하며 수정한 파일·옮겨온 PC 원본은 삭제하지 않습니다. 영구 삭제를 켜기 전에 안내를 확인하세요.
- 새 회차 확인은 설정을 켜면 주기적으로 확인합니다. 첫 조회는 기준 목록을 만들고 신규 회차만 기록합니다. 앱 내 알림에서 내 목록 추가·최신화 다운로드. 기기 알림에는 Android 알림 권한이 필요합니다.
- 공개 GitHub 친구 추천·동감·삭제 요청, 내 목록 전체 공유, 개인/공유 사이트. 등록은 GitHub 본인 계정으로 요청을 제출해야 합니다. 마스터 계정 관리·메뉴 이름 설정은 계정 서버에서 권한을 검사합니다.
- 화이트·다크·레인보우·회색·강조형, 이미지 공백 배경색·읽기 폭·상단 숨김·회차 선택, APK 회차 CBZ 내보내기. Windows OpenComic 별도 실행과 PC 전원 종료는 Android에서 제공하지 않습니다.
- 최신 APK를 앱에서 내려받아 SHA-256·앱 ID·버전·서명을 확인한 뒤 Android 설치 화면을 엽니다. 설치 승인과 필요한 출처 허용은 사용자가 Android 화면에서 선택합니다. 같은 서명과 앱 ID로 업데이트하면 기존 앱 데이터·폴더 연결이 유지됩니다. 앱을 삭제하면 앱 내부 기록이 삭제됩니다.

## PC와 함께 배포

버전은 PC `sharing.py`, Android `versionName/versionCode`, 모바일 표시를 함께 올립니다. `prepare_android.py`는 비밀키·암호·빌드 출력 없이 재현 가능한 소스 ZIP을 준비합니다. 통합 release 작업은 Windows 검사와 Android 단위 검사·Lint·서명 APK 빌드가 모두 통과한 뒤 같은 릴리스에 PC 패치와 APK를 게시합니다. 서명키는 공개 소스에 포함하지 않습니다. Actions Secrets 연결 전에는 배포자가 로컬에서 APK에 서명하여 게시해야 합니다.

웹앱도 유지합니다: https://redmonbi.github.io/ToonShelf/mobile/ . 웹앱의 폴더 가져오기는 브라우저 제한 때문에 선택한 이미지를 앱 저장소에 복사하며 Android 직접 다운로드·예약·원본 폴더 연결은 APK 기능입니다.

실제 휴대폰/태블릿 기기는 이 개발 환경에 연결되지 않아 실제 기기의 제조사별 파일 선택기·절전 동작 검사는 아직 수행하지 않았습니다. 빌드·Android 단위 검사·Lint·휴대폰/태블릿 화면과 브리지 모의 검사를 수행합니다.


## 읽는 순서와 기존 폴더 복구

PC에서 라이브러리의 **폴더 이동용 순서 기록 저장**을 실행한 뒤 각 회차의 `_reading_order.json`을 이미지와 함께 복사하세요. 앱에서 대표 폴더를 새로고침하면 임의 파일명 대신 기록된 순서로 읽습니다. 기존 작품 카드의 **사이트 순서 다시 맞추기**에서 현재 사이트 주소 또는 작품 링크를 지정하면 원본 파일을 보존하고 이 앱의 순서 기록을 다시 만듭니다. 이름·주소가 매칭되지 않은 회차는 보류하며 누락 이미지는 해당 위치에 표시합니다. 앱의 복구 기록은 이 기기 내부에 저장하므로 재이동 시에는 PC 순서 기록이나 CBZ를 사용하세요. 실제 기기의 설치·사이트 접근은 제조사와 연결 상태에 따라 추가 확인이 필요합니다.
